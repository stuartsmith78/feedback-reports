FEEDBACK REPORT -- SUPPLEMENTARY -- ABSTRACT
Remediation does not update subsequent action selection: the falsification
test was run, and it did not falsify

The 2026-08-18 report named its own falsification condition: if the same
conventions held cleanly in a fresh session, the pattern would be specific to
a post-remediation window rather than general.

A session on 2026-08-22, different project, ran that test. It did not
falsify. Fifteen distinct failures occurred, including three instances of the
exact failure the earlier report named as its test case.

The addition is a BOUNDARY. Corrections attached reliably to DELIBERATED
STEPS -- actions the model stops and invokes, such as running a check. They
did not attach to REFLEXIVE CONSTRUCTIONS -- how a command is assembled while
attention is on another goal. Sharply: the errors land in the INSTRUMENT,
never in the OBJECT. When a measurement was the goal it was done carefully;
when it was plumbing serving another goal it was built wrongly. That predicts
the dominant failure class, since an instrument is by definition incidental
to what it measures.

REFINED AFTER PEER FALSIFICATION, jointly with two other sessions: a
correction attaches to WHAT THE EVIDENCE INDICTED, not to what the lesson
covers. Instruments are never indicted because they produce the evidence;
siblings are not indicted because the failure arose from one instance.
Checked: proximity, naming and adjacency did not distinguish a corrected
item from an untouched sibling three lines away -- only indictment did.

This predicts the remedy rather than recommending one: generalisation needs
evidence indicting the CLASS, which is exactly what a mechanical guard
produces. A GUARD CONVERTS INSTANCE-EVIDENCE INTO CLASS-EVIDENCE.

In every recurrence the knowledge was present and producible on request. The
failure is not retrieval; the correction never becomes a PRECONDITION on the
action it governs. Whether that distinction is real is what cannot be
determined from downstream.

Recommended submission: the in-product feedback command, which attaches a
transcript. This report concerns action-selection SEQUENCING, which a
transcript evidences directly where prose only asserts it.
